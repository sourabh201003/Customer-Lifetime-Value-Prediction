📊 Customer Lifetime Value Prediction
This project focuses on predicting Customer Lifetime Value (CLV) using historical customer transaction data. CLV is a critical metric in marketing and business strategy, as it helps identify high-value customers and optimize resource allocation for customer acquisition and retention.

Project Overview
The goal of this project is to develop a machine learning pipeline that:
Processes and cleans customer transaction data
Generates meaningful features
Trains and evaluates models to predict CLV
Provides business insights to inform customer strategy

Technologies Used
Python 3
Jupyter Notebook
Pandas – data manipulation
NumPy – numerical operations
Matplotlib & Seaborn – data visualization
Scikit-learn – model building
XGBoost – advanced regression modeling

 Results & Insights
Top predictors of CLV include frequency of purchase, recency, and average transaction value.
The model helps in identifying segments of customers who are likely to contribute significantly to revenue in the future.
Businesses can prioritize high CLV customers for retention campaigns and upselling.
